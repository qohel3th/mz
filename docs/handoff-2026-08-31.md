## Known issues / gotchas
- `components/chart/Hexagon.tsx:48` sets `height="auto"` on an `<svg>` → console error on `/dashboard`
  (pre-existing, untouched).
- `Math.sin/cos` coordinates must be rounded (`r2`) before rendering in SVG — server/client float last digits
  differ and break hydration (bit us on the map).
- Playwright can't real-click the journal dog-ear under CSS `perspective` (hit-test returns `<html>`); tests
  dispatch the click. Real touch works — worth one tap on a phone.
- `useT()` always returns the chrome locale (`en`) and `HtmlAttrs` pins `<html lang="en" dir="ltr">`; Hebrew
  inside the diary is done explicitly with `makeT("he")`, not via locale switching.
